## 修复与边界

修复了长 Git diff 截断配置字段、配置缺少路径、无日志但有文档答案仍被判为等待补充的问题；明确文件查询应直接检索，并避免模型擅自选择 INFO 等级而漏掉相关日志。

结构化引用验证只能证明引用存在，不能证明模型每句话均准确。模型有时仍会混淆抽样中的分类条数和全量分布；全量统计以页面检索统计及原始证据为准。已有的“误称没有日志”保护会在与实际命中矛盾时改用带原始日志的检索摘要。真实 GitHub 写入仍是接口桩；本轮没有执行外部建单或验证生产部署。
