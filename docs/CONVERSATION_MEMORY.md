# 持久会话与可恢复追问

2026-09-25。基于 Go / PostgreSQL / LangGraph / Mistral，通过结构化状态保存会话上下文和最新查询意图。

## 已交付

- 工作台普通问答、澄清、业务查询和日志调查统一写入持久对话。刷新、重新登录后可以选择历史对话继续问；当前浏览器页按账号保存所选对话 ID，正文和历史由服务端加载。
- 新对话隔离上下文；旧业务查询点击只查看该次结果，不会偷偷替换当前对话的上下文。对话中的任务按钮关联真实查询记录，数值、SQL、执行时间仍以任务结果为准。
- 每段对话保存最新查询意图、任务 ID、来源数据集与配置版本、时间和时区；最近最多四轮问答与查询意图一起供路由理解追问。长对话可加载更早消息，模型上下文有界；超预算时舍弃较早整轮，保留完整问题末尾约束。
- 追问重新检查当前权限、重新执行查询。历史结果没有复制到记忆中当作当前事实，历史助手说明也明确标记仅为任务引用。
- 创建与消息提交具有幂等键；同段对话使用版本和短数据库事务串行入场，模型调用期间不持有数据库事务。两个页面同版本提交只接受一个。
- 请求中断可重试；租约 180 秒，过期后重试使用新执行凭证，旧请求不能覆盖新结果。下游任务使用固定消息 UUID 作为幂等键，避免重新创建业务查询。
- 对话属于创建者。记录用过的团队/数据集权限；当前权限撤销或数据集停用后，列表、读取、续问、完成回写均受限制。此版本采取整段隐藏策略。

## 数据与接口

新增迁移 `db/migrations/006_conversation_sessions.sql`，包含 `conversations`、`conversation_turns` 和 `query_datasets.version`。本机旧卷使用增量迁移，无重建数据。`scripts/deploy-local.sh`、隔离 Go 测试脚本和 OpenAPI 已同步。

| 接口 | 用途 |
|---|---|
| POST `/api/v1/conversations` | 幂等创建，正文 `{}` |
| GET `/api/v1/conversations?offset=0` | 当前账号可见的最近 50 段对话 |
| GET `/api/v1/conversations/{id}?before=...` | 最新 50 条消息记录，按序号向前分页 |
| POST `/api/v1/conversations/{id}/turns` | `text / mode / timezone / revision`；历史仅从服务端读取 |

两个 POST 必须携带 `Idempotency-Key`。同一键重试需保持完整输入不变。版本冲突后先读取最新对话，核对上下文，再用新键提交。旧 `/queries` 接口仍兼容无持久会话客户端；工作台已使用新接口。

## 手动体验

1. 刷新 `http://localhost:8088/`，登录 Alice，点击“新对话”。
2. 问“2025年1月华东地区销售额是多少？只返回金额”。
3. 刷新页面或退出后重新登录，继续问“换成2月，其他条件不变”，应查到 **17508**。
4. 问几轮知识问题，再说“回到销售查询，地区换成华南”，应沿用2月。
5. 点击“新对话”后问“那华东呢”，应补问指标/时间，不继承前一段。

## 仍有边界

这一步是持久会话和查询意图锚点，**不是完整的结构化查询规划器**。时间、指标、分组、筛选尚未拆成独立可校验的计划字段；摘要记录来源配置版本，不是数据库快照版本。相对日期使用时间戳辅助模型解释，跨日含糊追问仍需扩展验收。

每段最多 500 条消息记录；路由使用最新四轮加最新查询意图，不承诺任意久远的聊天细节都能回忆。单条问题限制 2000 字，上下文超预算时舍弃较早整轮；没有对话删除、保留期限治理或跨会话语义搜索。账号当前浏览器页只保存对话 ID；新设备默认打开最新对话并可手选历史。

普通问答仍是模型输出；有限用例通过不代表任意输入都准确。当前业务库仍为 115 条教学订单；新会话能力没有扩大数据源或增加联网搜索。查询规划、复杂 Schema 检索、大规模业务数据评估、图表/导出/取消等继续按 [能力清单](CAPABILITIES.md) 推进。本轮验收环境为本机 Compose，未完成 Kubernetes 问数服务部署验收。
