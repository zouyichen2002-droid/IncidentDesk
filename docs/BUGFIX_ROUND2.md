# 第二轮边界测试与修复

2026-09-25，接续持久会话版本。修改已部署到本机 `http://localhost:8088/`；本轮仍使用 Mistral 和原教学数仓。

## 修复内容

| 问题 | 修复与验证 |
|---|---|
| 上一条回答到达时，清空用户正在输入的下一条草稿 | 只清空与已发送问题相同的输入；重试不清草稿。浏览器复现旧版草稿变空，修复后仍保留“下一条草稿：什么是锁？” |
| 切换对话时沿用另一段的未发送文字与查询方式 | 当前页面按对话分别保存草稿和方式，切回原对话恢复；退出登录不保留草稿。浏览器实测业务方式切换后新对话为自动，返回恢复原草稿和方式 |
| 恢复历史失败后，后续发送可能静默新建空对话 | 增加明确的恢复失败状态，禁用发送并提供重新加载；保留目标对话 ID。停 API 模拟 502，发送禁用，服务恢复后重新加载同一段且保留草稿 |
| 快速点击不同查询，较慢的旧响应可能覆盖新选择 | 查询详情和轮询增加请求序号检查；切换对话、提交新问题、收起结果时使旧响应失效。代码路径复核与前端构建通过；未用浏览器网络拦截强制调换响应顺序 |
| 恢复不在前 50 项中的对话后，“更多对话”分页漏项 | 页偏移只统计服务端返回的分页项，不把额外插入的当前对话算进去。创建 53 段临时 Carol 对话，恢复最旧一段后加载第二页，页面完整显示 53 个不同 ID；测试记录已精确清理 |
| 长问题末尾的筛选条件在历史记忆中被截断 | 查询意图与时间说明拆开，保存完整问题；上下文预算超限时舍弃较早整轮，不切断问题末尾。新增 Go 回归先失败后通过；真实模型验证条件放在第 1500 字之后，仍保留地区/指标并正确追问换月份 |
| 长对话标题超出下拉框边界，长历史问题占满列表 | 下拉框随容器缩放；历史列表标题最多显示两行，完整问题仍可在详情查看 |

另补充了工作台 401 处理（返回登录页）和非 JSON 网关错误提示。瞬时断线不会再直接展示 JSON 解析异常。

## 边界

草稿只在当前页面内保留，刷新或退出会丢弃未发送内容；已提交对话仍在数据库。模型上下文为最多四轮加最新查询意图，超预算时可少于四轮。本轮没有完成任意长期记忆、结构化查询计划、大规模业务数据评估或生产可用性验收。
