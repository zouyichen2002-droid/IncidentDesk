# 页面验证（2026-09-25）

通过 Codex 浏览器操作 http://localhost:8088/，Alice 登录态：

- 新入口显示普通问答、业务查询、日志调查和“新对话”按钮。
- 两字输入“你好”可提交，返回普通回答；“你是谁”返回 IncidentDesk / Mistral 身份与能力。
- “客单价是什么意思？”返回公式、解释和明确标为举例的数值，不创建业务查询。
- 回复有“助手回复 · 模型回答”标识，与实际 SQL 结果区分。
- 查看“已审核记忆”再返回统一工作台，“你是谁”的对话仍存在。
- 刷新页面按提示清除对话，数据库查询历史保留。
- 页面无水平溢出，输入框、模式、发送和新对话可用。

后端验收与有限样例结果见 summary.json；页面检查不代表任意问法均正确。
