## 外部阻塞

- 尚无用户指定并授权的 GitHub 测试仓库/token。写入协议、重复批准、丢响应和回读均使用显式持久化 HTTP 桩；Git 源是本地真实提交，尚非独立远程 GitHub 演示仓库。获得配置后需迁移演示仓库、连接真实来源并审批真实 Issue。
- 本机真实 Mistral 已接通并有问数/调查验收记录。公开仓库不包含密钥；使用者需自行配置。动态调查对比、系统成本评估和独立人工质量评分仍未完成。
- 未获取独立人工评分者/试用者。24 个固定变体的 48 次确定性规则运行不是人工调查有效率。AC-03 的 ≥80% 尚无可报告分子/分母；人工 badcase 确认和真实试用反馈也不虚构。
- GitHub Actions 的实际状态以仓库 Actions 页面为准；历史本机检查不等于每次提交的远端 CI 结果。

## 明确的工程边界

- 单 PostgreSQL、单本地对象存储，备份恢复不等于 HA。Chart 的演示账号和 Secret 仅适合隔离本机；生产 OIDC/TLS/Secrets/备份保留需另外配置。
- 网络策略按受信应用组与独立沙箱/演示命名空间隔离，未声称每个内部服务之间完全零信任。固定沙箱程序不是通用不可信代码执行平台。
- 源 ACL 由 Go 的团队/服务权限控制。日志增量游标、SQL 版本、Git/Markdown 版本重扫与可信变更通知已实现；未实现外部企业目录 ACL 自动同步。
- 查询每源最多 50 条默认记录；明确显示截断/缺口。Ontology 是有限类型与关系，不是开放知识图谱或通用 SQL 代理。多个来源独立采集，没有分布式一致快照。
- Context 缓存 TTL 30 秒、以当前身份/团队/时间/水位隔离。来源通知使旧报告/审批/记忆不可用；不可达的 checkpoint/对象由保留作业物理清理，备份由运营者另行治理。
- GitHub 结果核对最多扫描 500 条近期 Issue；找不到或有歧义保持 unknown，需要人工核对，绝不自动再次 POST。
- 默认报告是明确标记的确定性基线；固定词规则只提出候选，不证明根因。固定数据上的模块扰动实验不能作为真实 Agent 收益结论。
- SSE 保留审计元数据并支持游标补发；异常/过期游标通知前端重载快照。当前审计元数据没有自动永久删除策略，部署者需确定法律/运营保留期限。
- API OpenTelemetry span 与持久化业务事件共同提供任务/工具/审批/动作关联；本地只输出结构化日志，没有托管 trace 后端或生产采样策略。
- 性能报告是 macOS Docker 本机、确定性执行器结果，不是模型吞吐、生产 SLA 或跨硬件承诺。每项证据对应当时的镜像/脚本，最终小幅 UI/治理修复未重复 10 分钟压测。
